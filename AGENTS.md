# Conversation Design Skills

This repository contains standalone skills for AI agents that design conversational
and voice experiences. Keep each skill's instructions, references and examples
together in its folder so the installed folder works independently.

## Writing and checks

Skills are Markdown. Every rule should be testable: give a test prompt and an
expected result, as `personality-controls` does. Write in plain English; Spanish
examples are welcome.

## Branch workflow

Use a feature or fix branch for changes. Keep unrelated skills separate. Do not
commit client material, real conversation transcripts, personal data,
credentials, or machine-specific paths.
